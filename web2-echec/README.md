# Web2 Echecs

## Structure

- `frontend/src/` : application React/Vite
- `backend/` : serveur Express et base SQLite

## Lancer le projet

Depuis le dossier `web2-echec` :

```bash
npm run dev
npm run dev:backend
```

Le frontend est disponible sur `http://localhost:5173` et l'API sur `http://localhost:3000`.

## Vérifications

```bash
npm run build
npm run lint
```
